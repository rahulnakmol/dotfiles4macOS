Current workspace setup

15 variants · 30 Laptop/Desk recipes · 45 action aliases. Focus defaults to 45 minutes, with 30/25 available. Slack remains the desktop chat companion in Code and Write. Meet Teams uses Teams + Notion + Edge; Meet Zoom uses Zoom + Notion + Zen. Wispr Flow starts at login and no workflow launches it.

Native cleanup: applied and verified. Existing Slack keys and favorites stay intact. Shift–A/X/D and unshifted O are freed by retiring unused variants; Write with Slack keeps Control–Option–Shift–O.

How the setup works

Raycast owns window placement, DockFlow owns the Dock, and Session owns timers. Workspace applies the Dock preset and requests the layout; Arrange changes the layout only; Focus prepares the workspace, confirms readiness, then requests a timer. No custom extension or developer mode is required.

Desk uses the calibrated main/support external displays; Laptop uses the one active display. Three or more displays require saved external display IDs. Complete Raycast’s external-command prompt before confirming Focus readiness. Notion stays minimized in Code; Remote Work preserves already-running remote clients.

Native layout recipes

Widths are shown as fractions, such as 2/3 and 1/3. Full width means the entire display.

The layout leader is l: las = Auto Amp + Slack, lasl = Laptop, lasd = Desk. This is one category leader plus two or three mnemonic letters. Design uses a 2/3–1/3 primary/browser pair on Laptop and one maximized app per Desk display. Meet uses a 2/3 meeting-client / 1/3 Notion pair, with Edge (Teams) or Zen (Zoom) on support; Laptop keeps the browser maximized behind the pair. Code keeps its primary app beside Slack, with Zen/Ghostty on the support display.
