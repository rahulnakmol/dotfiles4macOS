# dotFiles for macOS

This repository contains my dotfiles for macOS personalised to catppuccin theme.
It includes configurations for the following tools:

- zsh (shell)
- neovim with NVChad (text editor)
- tmux (terminal multiplexer)
- git (version control)
- kitty (terminal emulator)
- iTerm2 (terminal emulator)
- starship (shell prompt)

## Installation

1. Clone the repository

```bash
git clone https://github.com/rahulnakmol/dotfiles-for-macOS.git ~/.dotfiles
```
